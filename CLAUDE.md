# sv_pages — контекст для Claude

HTML-справочники пользователя (Сергій, GitHub Svor89), публикуются через GitHub Pages:
`https://svor89.github.io/sv_pages/<файл>.html`. Их же показывает программа SV (`C:\Claude\SV`, отдельный репозиторий)
во вкладке «Довідники» — в своём окне (WebView2), с офлайн-копией; .html может быть скачан и открыт отдельно
(«Хмарна папка» SV). Цель — страница работает без интернета и весит минимум (её потом вшивают в SV).

## Шаблон «Dark Cyber» (`template.html`) — стиль по умолчанию для всех справочников
- Страница полностью самодостаточна, ~40 КБ: свой CSS (без Tailwind), системные шрифты (Segoe UI / Cascadia Mono,
  Consolas — 0 байт), иконки — встроенные SVG, логотип — base64 WebP 64 px (`tools/logo64.webp`, 1,6 КБ; он же favicon —
  ставит скрипт). Никаких CDN, Google Fonts, Font Awesome CSS, внешних картинок — пользователь просил (2026-10-25):
  до этого страница тянула ~1 МБ (Tailwind CDN 400 КБ, Font Awesome ~385 КБ, шрифты Google).
- Новая страница: копия `template.html`, правится `<title>`, заголовок в шапке и `<main>`. Стили и `<script>` одинаковы
  во всех страницах — правка там = правка во всех файлах.
- Блоки (образцы в шаблоне): раздел `section.card data-c="purple|cyan|amber|emerald|rose"`, `.head` (.num, h2, .badge),
  `.lead`, `.chips`, `.note` (`.info`, `.bad`), `.btns` > `a.btn` (`.main`), `.cmd` (команда + `button.copy data-copy`),
  `details` (summary «Розгорнути/Згорнути»), `.step`, `ol.list`, `code.k`, `.tabs` > `button data-tab` + `.pane`.
- Команды — один источник: «Усі команди» — `<pre data-collect="id блока шагов" data-after="хвост">`, скрипт собирает
  сам; не дублировать команды вручную. Команды переносятся по строкам, не обрезаются.
- Иконки: `<svg class="i"><use href="#i-ИМЯ"/></svg>`; после правок — `python tools/icons.py` (кладёт в страницу ровно
  используемые иконки из `tools/icons/`). Новая иконка — Font Awesome Free 6.4.0 (CC BY 4.0), команда — в шапке скрипта.

## Светлая тема «Light» (2026-10-26, просьба пользователя: альтернатива Dark Cyber в стиле окон SV)
- Средние тона, не белая (2-я версия по просьбе пользователя): тёмно-синяя шапка, фон сине-серый (#bcc7d4, градиент),
  карточки серые #dde3ea, вложенные блоки на тон темнее, раскрытое — светлее; акцент — голубой/синий: purple в Light перекрашен в синий (#0369a1),
  остальные цвета разделов — тёмные оттенки 700/800, кнопки — сплошная заливка с лёгкой тенью.
- Включается классом `light` у `<html>`. Порядок: выбор кнопкой ☀/☾ в шапке (localStorage `theme`) → параметр
  `?theme=light|dark` (так тему задаёт SV) → тёмная. Скрипт в `<head>` ставит класс до отрисовки — без мигания.
- CSS — блок `:where(.light) …` перед `@media print`: `:where()` без веса, перекрывает тёмные правила только порядком,
  поэтому правила конкретной страницы ниже (2 столбца в Windows-Office Act) работают в обеих темах.
  Новый цвет в тёмных стилях — сразу добавить пару в блок Light. `.term` (имитация консоли) чёрная в обеих темах.


## Таблицы данных (коды, адреса, номера) — общий стиль, 2026-10-26 (пользователь: «этот стиль — база для подобных данных»)
- Образец — «Розділ 3» в `template.html`, живой пример — `Organ-Codes.html` (данные из «Кодировки органов+айпи.docx»).
- `Organ-Codes.html` — только коды органов ЄРДР/ЖЄО (пользователь: публиковать можно). Блок внутренних IP-адресов
  убран по решению пользователя — внутренние адреса сети на GitHub Pages не выкладывать.
- Разметка: `.tw` > `table.tbl`; первая колонка — название (прижата к данным: ширина по тексту, без переноса от 481 px);
  значение — `button.v data-v="…"` («таблетка», клик копирует, тост «Скопійовано: …»). Строки — «зеброй» без линий,
  под курсором подсвечиваются. Группа колонок — `th.grp colspan` + строка `tr.sub` с подзаголовками (остальные `th rowspan="2"`).
  Колонку другого смысла выделять цветом таблеток: `data-c` на её `th` и всех `td` (а не заливкой столбца — пользователю не понравилось).
- Несколько таблиц на странице — блоки в ряд своим CSS страницы (как в Organ-Codes: от 900 px два столбца, `.wrap` 62rem,
  уже — друг под другом, 36rem; одна таблица — просто 36rem): широкие пустые таблицы пользователь не любит. `.card>.tw{flex:1}` — карточки ряда одной высоты.

## Правила
- Картинки — только встроенные base64 (`data:image/webp;base64,...`), маленького размера; отдельных файлов картинок
  страницы не используют.
- Интерфейс страниц — на украинском. Общение с пользователем — по-русски. Комментарии в коде — по-русски.
- Адреса и команды пользователя (например KMS-сервер) не менять без его просьбы.
- Проверка: открыть страницу в Edge без сети (всё на месте, консоль чистая), копирование/вкладки, узкий экран без
  горизонтальной прокрутки; после push — GitHub Pages через 1–2 мин. Коммит и push — с разрешения пользователя.
