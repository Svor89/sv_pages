# sv_pages — контекст для Claude

HTML-справочники пользователя (Сергій, GitHub Svor89), публикуются через GitHub Pages:
`https://svor89.github.io/sv_pages/<файл>.html`. Их же показывает программа SV (`C:\Claude\SV`, отдельный репозиторий)
во вкладке «Довідники» — в своём окне (WebView2), с офлайн-копией; .html может быть скачан и открыт отдельно
(«Хмарна папка» SV). Цель — страница работает без интернета и весит минимум (её потом вшивают в SV).

## Система «SV Довідники» (`design.md`, 2026-10-31) — стиль всех текущих и будущих страниц
- Полный редизайн по методу Hallmark (github.com/nutlope/hallmark) по просьбе пользователя: тема Almanac (справочник:
  сланцевая бумага, линейки, квадратные углы, моноширинные цифры) в режиме app screen. Сам скил НЕ установлен
  (вариант «Б»: метод, не инструмент) — он под лендинги, тянет шрифты с CDN, требует Node. Правила — в `design.md`,
  читать его первым перед любой новой страницей.
- Страница самодостаточна, ~30–50 КБ: системные шрифты (Segoe UI Variable / Cascadia Mono — 0 байт, с кириллицей),
  иконки — встроенные SVG, логотип — base64 WebP (`tools/logo64.webp`; он же favicon). Никаких CDN, Google Fonts,
  внешних картинок (пользователь, 2026-10-25). Цвета — hex, не oklch (старые WebView2).
- Общие части — в `tools/`: `base.css`, `base.js`, `head.js` (тема до отрисовки). `python tools/build.py` вставляет их
  в каждую страницу между `<!--base-->…<!--/base-->` и `<!--base-js-->…<!--/base-js-->` и кладёт используемые иконки
  между `<!--icons-->…<!--/icons-->`. В самих страницах общий CSS/JS не править. Свой CSS страницы — `<style>` после
  блока base, только `var(--токен)`. В HTML-комментариях не писать `-->` (метка `<!--/base-->` в комментарии его ломает).
- Новая страница: копия `template.html` (образцы всех блоков), правятся `<title>`, description, заголовок шапки, `<main>`.
  Блоки: `section.sec` (`data-c="blue|teal|amber|green|red"`, без него — акцент), `.head` (.num «01», h2, .tag),
  `.lead`, `.prose`, `dl.facts`, `.chips`, `.note` (`.info`, `.bad`), `.btns > a.btn` (`.main`), `.cmd`, `.step`,
  `details` / `details.q` (FAQ), `ol.list`, `ol.how` (шаги инструкции), `code.k`, `.tabs` > `button data-tab` + `.pane`,
  `nav.toc[data-toc]` (оглавление), `.search > input[data-search]` + `.empty` (поиск по вопросам, `?q=`, `#id`).
- Команды — один источник: «Усі команди» — `<pre data-collect="id блока шагов" data-after="хвост">`, скрипт собирает
  сам; не дублировать вручную. Команды переносятся по строкам, не обрезаются; команда — тёмная полоса в обеих темах.
- Новая иконка — Font Awesome Free 6.4.0 (CC BY 4.0) в `tools/icons/`, команда — в шапке `tools/build.py`.
- `test_Dark Cyber.html` — старая тестовая страница прежнего стиля, `build.py` её пропускает (нет меток).

## Темы
- Две темы из одного набора токенов: `:root` — тёмная, `:root.light` — светлая (сланец #c4cbd2, листы #e7ecf0,
  тёмно-синяя шапка, акцент синий #0058a3 — пользователь просил упор на синий, не фиолетовый). Новый цвет — токен
  в обоих блоках `tools/base.css`, контраст текста ≥ 4,5:1.
- Включение — класс `light` у `<html>`: кнопка ☀/☾ (localStorage `theme`) → `?theme=light|dark` → тёмная. SV
  (`C:\Claude\SV\src\Tools\Web`) открывает страницы с `?theme=light` и пишет localStorage — механизм не менять.

## Таблицы данных (коды, адреса, номера) — общий стиль, 2026-10-26 (пользователь: «этот стиль — база для подобных данных»)
- Образец — «Розділ 3» в `template.html`, живой пример — `Organ-Codes.html` (данные из «Кодировки органов+айпи.docx»).
- `Organ-Codes.html` — только коды органов ЄРДР/ЖЄО (пользователь: публиковать можно). Блок внутренних IP-адресов
  убран по решению пользователя — внутренние адреса сети на GitHub Pages не выкладывать.
- Разметка: `.tw` > `table.tbl`; первая колонка — название (прижата к данным: ширина по тексту, без переноса от 481 px);
  значение — `button.v data-v="…"` («таблетка», клик копирует, тост «Скопійовано: …»). Строки — «зеброй» без линий,
  под курсором подсвечиваются. Группа колонок — `th.grp colspan` + строка `tr.sub` с подзаголовками (остальные `th rowspan="2"`).
  Колонку другого смысла выделять цветом таблеток: `data-c` (напр. green) на её `th` и всех `td` (а не заливкой столбца — пользователю не понравилось).
- Несколько таблиц на странице — блоки в ряд своим CSS страницы (как в Organ-Codes: от 900 px два столбца, `.wrap` 62rem,
  уже — друг под другом, 36rem; одна таблица — просто 36rem): широкие пустые таблицы пользователь не любит. `.sec>.tw{flex:1}` — разделы ряда одной высоты.

## Правила
- Картинки — только встроенные base64 (`data:image/webp;base64,...`), маленького размера; отдельных файлов картинок
  страницы не используют.
- Интерфейс страниц — на украинском. Общение с пользователем — по-русски. Комментарии в коде — по-русски.
- Адреса и команды пользователя (например KMS-сервер) не менять без его просьбы.
- Проверка: открыть страницу в Edge без сети (всё на месте, консоль чистая), копирование/вкладки, узкий экран без
  горизонтальной прокрутки; после push — GitHub Pages через 1–2 мин. Коммит и push — с разрешения пользователя.
