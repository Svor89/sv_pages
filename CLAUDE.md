# sv_pages — контекст для Claude

HTML-справочники пользователя (Сергій, GitHub Svor89), публикуются через GitHub Pages:
`https://svor89.github.io/sv_pages/<файл>.html`. Их же показывает программа SV (`C:\Claude\SV`, отдельный репозиторий)
во вкладке «Довідники» — в своём окне (WebView2), с офлайн-копией; .html может быть скачан и открыт отдельно
(«Хмарна папка» SV).

## Правила
- Каждая страница самодостаточна: картинки (логотип `sv.webp` и любые новые) — встраивать base64
  (`data:image/webp;base64,...`), не относительными путями — отдельных файлов картинок в репозитории нет.
  Источник логотипа — `C:\Claude\SV\test\sv.webp`.
- Стиль — Tailwind CDN + Google Fonts + FontAwesome, тёмная тема «Dark Cyber» (образец — `test_Dark Cyber.html`).
- Интерфейс страниц — на украинском. Общение с пользователем — по-русски.
- Файлы — UTF-8, CRLF; правки точечные, остальное в странице не трогать.
- Проверка: открыть страницу локально в Edge (картинки на месте), после push — на GitHub Pages через 1–2 мин.
