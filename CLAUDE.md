# sv_pages — контекст для Claude

HTML-справочники пользователя (Сергій, GitHub Svor89), публикуются через GitHub Pages:
`https://svor89.github.io/sv_pages/<файл>.html`. Их же показывает программа SV (`C:\Claude\SV`, отдельный репозиторий)
во вкладке «Довідники» — в своём окне (WebView2), с офлайн-копией; .html может быть скачан и открыт отдельно
(«Хмарна папка» SV). Цель — страница работает без интернета и весит минимум (её потом вшивают в SV).

## Шаблон «Dark Cyber» (`template.html`) — стиль по умолчанию для всех справочников
- Страница полностью самодостаточна, ~35 КБ: свой CSS (без Tailwind), системные шрифты (Segoe UI / Cascadia Mono,
  Consolas — 0 байт), иконки — встроенные SVG, логотип — base64 WebP 64 px (`tools/logo64.webp`, 1,6 КБ; он же favicon —
  ставит скрипт). Никаких CDN, Google Fonts, Font Awesome CSS, внешних картинок — пользователь просил (2026-10-25):
  до этого страница тянула ~1 МБ (Tailwind CDN 400 КБ, Font Awesome ~385 КБ, шрифты Google).
- Новая страница: копия `template.html`, правится `<title>`, заголовок в шапке и `<main>`. Стили и `<script>` одинаковы
  во всех страницах — правка там = правка во всех файлах.
- Блоки (образцы в шаблоне): раздел `section.card data-c="purple|cyan|amber|emerald|rose"`, `.head` (.num, h2, .badge),
  `.lead`, `.chips`, `.note` (`.info`, `.bad`), `.btns` > `a.btn` (`.main`), `.cmd` (команда + `button.copy data-copy`),
  `details` (summary «Розгорнути/Згорнути»), `.step`, `ol.list`, `code.k`, `.tabs` > `button data-tab` + `.pane`.
- Команды — один источник: «Усі команди» — `<pre data-collect="id блока шагов" data-after="хвост">`, скрипт собирает
  сам; не дублировать команды вручную. Команды переносятся по строкам, не обрезаются.
- Иконки: `<svg class="i"><use href="#i-ИМЯ"/></svg>`; после правок — `python tools/icons.py` (кладёт в страницу ровно
  используемые иконки из `tools/icons/`). Новая иконка — Font Awesome Free 6.4.0 (CC BY 4.0), команда — в шапке скрипта.

## Правила
- Картинки — только встроенные base64 (`data:image/webp;base64,...`), маленького размера; отдельных файлов картинок
  страницы не используют.
- Интерфейс страниц — на украинском. Общение с пользователем — по-русски. Комментарии в коде — по-русски.
- Адреса и команды пользователя (например KMS-сервер) не менять без его просьбы.
- Проверка: открыть страницу в Edge без сети (всё на месте, консоль чистая), копирование/вкладки, узкий экран без
  горизонтальной прокрутки; после push — GitHub Pages через 1–2 мин. Коммит и push — с разрешения пользователя.
