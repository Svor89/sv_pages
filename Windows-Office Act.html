Метод 1: Скрипт MAS (Microsoft Activation Scripts)

НАЗАВЖДИ

Офіційний відкритий інструмент від спільноти Massgrave для швидкої та вічної активації.

Вибір у меню MAS:
Windows: 1 (HWID) Office: 2 (Ohook)
Примітка: Тимчасово вимкніть антивірус або «Захист у реальному часі» для роботи скрипта.
Скачати MAS_AIO.cmd
Пряме завантаження `.cmd`
Скачати MAS_AIO.zip
Архів GitHub
Альтернатива через PowerShell (в 1 клік)
irm https://get.activated.win | iex
Покрокова інструкція
Розгорнути Згорнути
  1. Вимкніть антивірус та скачайте MAS_AIO.cmd або запустить PowerShell команду.
  2. Запустіть MAS_AIO.cmd у Командному рядку (cmd) від імені адміністратора.
  3. У вікні меню виберіть: 1 (HWID) для Windows або 2 (Ohook) для Office.
  4. Зачекайте 5 секунд до успішного завершення.

Метод 2: KMS-сервер через Командний рядок (cmd)

На 180 днів

Безпечна активація в Командному рядку (cmd) без зміни системних файлів. Антивірус вимикати не потрібно.

Запустіть Командний рядок (cmd) від імені адміністратора.

Усі команди для Windows (Автовідкриття та закриття)

cscript //nologo %windir%\system32\slmgr.vbs /skms kms.msguides.com
cscript //nologo %windir%\system32\slmgr.vbs /ato
cscript //nologo %windir%\system32\slmgr.vbs /ckms
cscript //nologo %windir%\system32\slmgr.vbs /dli
echo. & echo Натисніть будь-яку клавішу для виходу... & pause > nul & exit
Окремі команди Windows
Розгорнути Згорнути
Крок 1: Встановлення сервера
cscript //nologo %windir%\system32\slmgr.vbs /skms kms.msguides.com
Крок 2: Запуск активації
cscript //nologo %windir%\system32\slmgr.vbs /ato
Крок 3: Очищення конфігурації
cscript //nologo %windir%\system32\slmgr.vbs /ckms
Крок 4: Перевірка статусу
cscript //nologo %windir%\system32\slmgr.vbs /dli
Запустіть Командний рядок (cmd) від імені адміністратора (Office 2016 / 2019 / 2021 / 2024).

Усі команди для Office

cd /d "C:\Program Files\Microsoft Office\Office16"
cscript //nologo ospp.vbs /sethst:kms.msguides.com
cscript //nologo ospp.vbs /act
cscript //nologo ospp.vbs /remhst
cscript //nologo ospp.vbs /dstatus
echo. & echo Натисніть будь-яку клавішу для виходу... & pause > nul & exit
Окремі команди Office
Розгорнути Згорнути
Крок 1: Каталог Office
cd /d "C:\Program Files\Microsoft Office\Office16"
Крок 2: Встановлення сервера
cscript //nologo ospp.vbs /sethst:kms.msguides.com
Крок 3: Активація
cscript //nologo ospp.vbs /act
Крок 4: Очищення конфігурації
cscript //nologo ospp.vbs /remhst
Крок 5: Перевірка статусу
cscript //nologo ospp.vbs /dstatus
