Активація Windows та Microsoft Office

01

Метод 1: Скрипт MAS (Microsoft Activation Scripts)

Назавжди

Відкритий інструмент від спільноти Massgrave для швидкої та вічної активації.

Тимчасово вимкніть антивірус або «Захист у реальному часі» для роботи скрипта.
MAS_AIO.cmdПряме завантаження MAS_AIO.zipАрхів GitHub
Альтернатива через PowerShell 
irm https://get.activated.win | iex
Методи активації: [1] HWID - Windows [2] Ohook - Office
Покрокова інструкція
РозгорнутиЗгорнути
  1. Вимкніть антивірус та скачайте MAS_AIO.cmd або запустіть PowerShell команду.
  2. Запустіть MAS_AIO.cmd у Командному рядку (cmd) від імені адміністратора.
  3. У вікні меню виберіть: 1 (HWID) для Windows або 2 (Ohook) для Office.
  4. Зачекайте 5 секунд до успішного завершення.

Метод 2: KMS-сервер через Командний рядок (cmd)

На 180 днів

Активація через Командний рядок (cmd).
Антивірус вимикати не потрібно.

Команди та інструкція
РозгорнутиЗгорнути
Запустіть Командний рядок (cmd) від імені адміністратора.
Усі команди для Windows 

        


        

          Окремі команди Windows
            
РозгорнутиЗгорнути

          

            
Крок 1: Ключ KMS-клієнта (Windows 10/11 Pro)
cscript //nologo %windir%\system32\slmgr.vbs /ipk W269N-WFGWX-YVC9B-4J6C9-T83GX

              

            
Крок 2: Встановлення сервера
cscript //nologo %windir%\system32\slmgr.vbs /skms kms.msguides.com

              

            
Крок 3: Запуск активації
cscript //nologo %windir%\system32\slmgr.vbs /ato

              

            
Крок 4: Очищення конфігурації
cscript //nologo %windir%\system32\slmgr.vbs /ckms

              

            
Крок 5: Перевірка статусу
cscript //nologo %windir%\system32\slmgr.vbs /dli

Крок 1: Каталог Office
if exist "%ProgramFiles%\Microsoft Office\Office16\ospp.vbs" (cd /d "%ProgramFiles%\Microsoft Office\Office16") else (cd /d "%ProgramFiles(x86)%\Microsoft Office\Office16")
