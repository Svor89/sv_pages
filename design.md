# Дизайн: SV Довідники

Зафиксированная система всех страниц sv_pages (справочники, инструкции, FAQ, база знаний). Каждая новая страница
читает этот файл первой; страницы делят систему и различаются только содержимым. Менять — осознанно, файл и есть правило.
Основа — метод Hallmark (github.com/nutlope/hallmark, MIT): тема Almanac (справочник: сланцевая бумага, чернила,
линейки двух толщин, квадратные углы, цифры моноширинным) в режиме «app screen», адаптированная под правила проекта.

## Система
- Жанр: справочник / база знаний (Hallmark app scope: плотность, таблицы раньше карточек, без hero и маркетинга).
- Тема: Almanac, адаптация — системные шрифты (офлайн, 0 байт), синий акцент вместо мадженты (просьба пользователя:
  упор на синий), тёмная тема выведена из светлой по рецепту Hallmark (тон не меняется, бумага темнеет, слои светлеют).
- Две темы: светлая — основная (SV открывает страницы с `?theme=light`), тёмная — по умолчанию без параметра.
  Механизм прежний: класс `light` у `<html>`; кнопка ☀/☾ в шапке (localStorage `theme`) → `?theme=` → тёмная.
- Подпись системы: каждая команда — тёмная «консольная» полоса (`--code`) в обеих темах; значения в таблицах — «таблетки»
  моноширинным, клик копирует.

## Токены
Источник — `tools/base.css` (`:root` — тёмная, `:root.light` — светлая). Роли:
- Бумага `--paper` (фон окна), лист `--sheet` (раздел), колодец `--well` (зебра, наведение), `--hover`.
- Чернила `--ink` (заголовки), `--ink-2` (текст), `--muted` (подписи, заголовки таблиц), линейки `--rule` (тонкая),
  `--rule-2` (жирная: над разделом, под шапкой таблицы).
- Шапка `--band` / `--band-ink` / `--band-accent`; консоль `--code` / `--code-ink` / `--code-muted` / `--code-ok`.
- Акцент `--accent` / `--accent-2` (наведение) / `--accent-ink` (текст на акценте) / `--focus`.
- Тона разделов (`data-c="blue|teal|amber|green|red"` → `--tone` и подложка `--tint`). Тон — маркер (номер,
  иконка, вкладка, таблетка, линейка заметки), никогда не заливка раздела.
- Шрифты: `--sans` Segoe UI Variable Text, `--display` Segoe UI Variable Display, `--mono` Cascadia Mono / Consolas
  (все с кириллицей, встроены в Windows). Шкала 13 / 14 / 15 / 16 (текст) / 18 / 21 (заголовок раздела).
- Углы `--r: 2px` у кнопок и таблеток, у листов — 0. Теней нет: глубина — линейка и шаг бумаги.

## Компоненты (образцы — `template.html`)
- Раздел `section.sec`: лист с жирной линейкой сверху; `.head` = `.num` (01, моно, тон) + `h2` + `.tag` (подпись, без капса).
- Текст: `.lead`, `.prose` (статья, 70ch), `dl.facts` (термин — описание), `ol.list`, `ol.how` (шаги инструкции).
- `.note` (жёлтая), `.note.info` (синяя), `.note.bad` (красная): подложка тона и линейка слева.
- Кнопки `.btns > a.btn` — контурные; `.btn.main` — одна залитая на раздел.
- Команды: `.cmd`, `.step`, «Усі команди» `pre[data-collect]`; `button.copy` (залитая), `.copy.sm` (иконка на консоли).
- `details` — линейки сверху/снизу, без рамки; `details.q` — вопрос FAQ.
- Вкладки `.tabs` — подчёркивание тоном; таблица `.tw > table.tbl` — зебра без линий, `button.v data-v`.
- Навигация: `nav.toc[data-toc]` (оглавление собирает скрипт), поиск `.search > input[data-search]` + `.empty`
  (фильтрует `details.q`, `?q=` в адресе, `#id` открывает вопрос).

## Правила (Floor Hallmark, принятые здесь)
1. Цвет и шрифт — только через токены; в CSS страницы — `var(--…)`, без литералов.
2. Без `transition: all`; анимируются только цвет, `transform`, `opacity`; есть `prefers-reduced-motion`.
3. `overflow-x: clip` у `html` и `body`; узкий экран (360 px) — без горизонтальной прокрутки.
4. У всего интерактивного — `:focus-visible`; кнопки — `type="button"`.
5. Без «бровей» над заголовками, капса с разрядкой, подписей КАПСОМ в таблицах и метках; без эмодзи-иконок,
   карточек в карточке, градиентов и свечений.
6. Не выдумывать факты, цифры, адреса; команды и адреса пользователя не менять без просьбы.

## Отступления (на записи)
- Системные шрифты вместо «необычных»: правило проекта — офлайн и минимальный вес (Hallmark допускает их в app scope).
- Несколько залитых кнопок «Скопіювати» на странице: копирование и есть основное действие справочника.
- Таблетки `.v` высотой 30 px (меньше 44): плотность таблицы данных; цель клика — вся строка таблетки.

## Сборка
`tools/base.css`, `tools/base.js`, `tools/head.js` — общие; `python tools/build.py` вставляет их в каждую страницу
(между `<!--base-->…<!--/base-->` и `<!--base-js-->…<!--/base-js-->`) и пересобирает иконки. Стили конкретной
страницы — отдельный `<style>` после `<!--/base-->`, только на токенах.
