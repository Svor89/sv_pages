Розділ 1: Автоматичне розгортання ПЗ

ІНСТРУМЕНТИ

Шаблонний модуль для завантаження та автоматичного встановлення базового робочого середовища розробника.

Рекомендовані компоненти:
Браузер: Google Chrome IDE: VS Code
Примітка: Для виконання пакетних команд рекомендується запускати консоль від імені адміністратора.
Скачати Google Chrome
Офіційний інсталятор (64-bit)
Скачати VS Code
Офіційний сайт Microsoft
Встановлення через PowerShell (Winget)
winget install --id Google.Chrome -e --accept-source-agreements
Покроковий алгоритм дій
Розгорнути Згорнути
  1. Завантажте необхідні інсталяційні файли або скопіюйте команду пакетного менеджера.
  2. Відкрийте PowerShell від імені адміністратора.
  3. Вставте та виконайте команду встановлення програмного забезпечення.
  4. Перевірте успішність встановлення у списку програм.

Розділ 2: Налаштування середовища розробки

КОНФІГУРАЦІЯ

Автоматизовані скрипти для швидкого налаштування оточення на Windows та Linux системах.

Примітка: Виконуйте команди від імені адміністратора (або sudo).
Усі команди для Windows
winget install --id Git.Git -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Python.Python.3.11 -e
Write-Host "Середовище успішно налаштовано!" -ForegroundColor Green
Read-Host -Prompt "Натисніть Enter для завершення..."
Окремі команди Windows
Розгорнути Згорнути
Крок 1: Встановлення Git
winget install --id Git.Git -e
Крок 2: Встановлення Node.js LTS
winget install --id OpenJS.NodeJS.LTS -e
Крок 3: Встановлення Python 3.11
winget install --id Python.Python.3.11 -e
Усі команди для Linux
sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl build-essential python3 python3-pip
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
echo "Linux середовище успішно оновлено!"
Окремі команди Linux
Розгорнути Згорнути
Крок 1: Оновлення пакетів
sudo apt update && sudo apt upgrade -y
Крок 2: Встановлення базових утиліт
sudo apt install -y git curl build-essential python3 python3-pip
Крок 3: Встановлення Node.js
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - && sudo apt install -y nodejs
Скопійовано у буфер обміну!
